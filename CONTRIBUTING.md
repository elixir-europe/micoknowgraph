# ELIXIR Microbiome Community & MiCoKnowGraph insights

We are an enthusiast [community](https://elixir-europe.org/communities/microbiome) of researchers working on microbiome also affiliated to [ELIXIR Research Infrastructure](https://elixir-europe.org/).
The community proposed a project to the [ELIXIR BioHackathon 2026](https://biohackathon-europe.org/) aiming to build a Microbiome Community Knowledge Graph. 
You can learn more about the project by checking [here](https://github.com/elixir-europe/biohackathon-projects-2026/blob/main/16.md). 
Feel free to join us and contribute.

# How can I contribute?

It is possible to contribute to this project in two ways: 
- the first is write an issue about docs, scripts or any part of this GitHub or this project describing what is not working for you;
- the second is to prepare a Pull Request (PR) proposing doc/script changes or adding new ones.

In both cases it is required to read and agree the [AI-policy](./AI-policy.md)

# PR best practices 

Before to open a PR please make sure to follow the best practices listed below:

- Create the fork of this repo
- Create a new branch in your forked repo and add/modify according your rationale
- Create a new branch in this repo with the same name of the branch in your forked repo
- Create you PR
- Make sure to read and agree [CONTRIBUNTING](./CONTRIBUTING.md) and [AI-policy](./AI-policy.md)

# Maintainers

Maintainers of this project are in charge for reviewing your PR or answer to any issue. After revision process PR may be merged.
If a maintainer is contributing with a PR, revision and merging process will be carried out by remaining ones.
Please don't be afraid in case of long wait for you PR. We will review it as soon we can.
